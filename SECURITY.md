# Security Policy

## Reporting a Vulnerability

Please do **not** open public GitHub issues for security vulnerabilities.

Report privately to: `<maintainer-security-contact@example.com>`

Include:
- Affected commit/tag
- Reproduction steps
- Impact assessment
- Suggested remediation (if available)

## Response Expectations

- Initial acknowledgment target: within 7 days
- Remediation timeline depends on severity and complexity

## Supported Versions

This project is currently pre-1.0. Security fixes are applied to the latest `main` branch.
